# Changelog

All notable changes to agntz will be documented in this file.

## 0.0.0 - 2026-06-26

- Establish the public baseline for the agntz TypeScript and Python libraries.
- Publish active TypeScript libraries at `0.0.0`: `@agntz/contracts`, `@agntz/db`, `@agntz/client`, `@agntz/core`, `@agntz/stores`, `@agntz/memrez`, and `@agntz/sdk`.
- Publish the Python `agntz` package at `0.0.0`.
- Treat earlier public registry versions as experimental pre-baseline iterations.
