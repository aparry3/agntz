# Support

Use the channel that matches the request:

- Usage questions and troubleshooting: [GitHub Discussions](https://github.com/aparry3/agntz/discussions)
- Confirmed bugs: [bug report](https://github.com/aparry3/agntz/issues/new?template=bug_report.yml)
- Feature proposals: [feature request](https://github.com/aparry3/agntz/issues/new?template=feature_request.yml)
- Vulnerabilities: follow [SECURITY.md](./SECURITY.md) and report privately

Include the package and version, runtime version, operating system, manifest or
minimal code sample, expected behavior, and complete error output. Remove API
keys, credentials, personal data, and proprietary prompts before posting.

The hosted service and open source packages are currently public beta software;
there is no guaranteed response or resolution SLA.
