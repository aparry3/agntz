# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Project participants must be respectful, constructive, and considerate in all
project spaces. Harassment, discriminatory language, threats, and sustained
disruption are not acceptable.

Report conduct concerns privately through a
[repository security advisory](https://github.com/aparry3/agntz/security/advisories/new).
Maintainers will review reports confidentially and may remove content, restrict
participation, or ban participants when necessary to protect the community.
