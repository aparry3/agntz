Agntz Architecture Reorg Plan

Consolidate the TypeScript storage surface, remove the ambiguous platform library, and keep Python as a library/client SDK without a second hosted worker.

Status Clean-break implementation plan Date 2026-06-25

Decision

One storage package Replace @agntz/platform, @agntz/store-postgres, and @agntz/store-sqlite with @agntz/stores subpaths.
One hosted worker TypeScript @agntz/worker remains the only hosted execution service. Python keeps client and embedded SDK parity.
No compatibility wrappers This is a clean break. Docs, Dockerfiles, imports, and publish notes move directly to the new package names.

Target Dependency Graph

core runtime imports only contracts stores owns storage contracts and adapters client has no local package imports python no hosted worker

Package invariants

  • @agntz/client has no local Agntz package dependencies.
  • @agntz/core imports @agntz/contracts only among local packages.
  • @agntz/stores does not import @agntz/core.
  • @agntz/memrez does not import @agntz/core.
  • Hosts own identity, transport, tenant policy application, and webhooks.

Implementation Phases

Create @agntz/stores

Move storage contracts and existing memory/Postgres/SQLite implementations behind subpath exports. Keep driver-specific imports isolated to their subpaths.

Move platform contracts and policy

Move API-key, namespace-root, webhook-delivery contracts and namespace policy helpers into @agntz/stores/contracts.

Move worker webhook runtime

Move createWebhookDispatcher, signing, retry, and outbound delivery code into worker-owned source. Keep only persisted delivery types in stores.

Update app, worker, SDK, Docker, and docs

Replace imports, package dependencies, build steps, publish notes, and public docs with the new @agntz/stores subpaths.

Remove retired packages

Remove packages/platform, packages/store-postgres, and packages/store-sqlite after all active imports are gone.

Drop Python hosted worker

Delete agntz.server, the Python server extra, FastAPI/Uvicorn dependencies, server tests, and server README sections.

Python Scope

Keep
  • Hosted HTTP client parity with the TS worker API.
  • Embedded Python SDK/runtime, manifests, tools, resources, local stores, and memrez.
  • Python storage classes used by embedded/local SDK flows.
Remove
  • python/src/agntz/server.py.
  • agntz[server] optional dependency group.
  • FastAPI/Uvicorn dev dependencies unless another test still needs them.
  • Python tests and docs that describe self-hosting with agntz.server.create_app.
